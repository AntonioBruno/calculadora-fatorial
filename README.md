# Calculadora de Fatorial

Aplicação web desenvolvida com **HTML, CSS e JavaScript** para calcular o fatorial de números inteiros de forma simples e interativa.

## Acesse o projeto

**[Experimentar a Calculadora de Fatorial](https://antoniobruno.github.io/calculadora-fatorial/)**

## Funcionalidades

- Cálculo de fatorial de números inteiros não negativos.
- Interface interativa para entrada de valores.
- Botão para executar o cálculo.
- Exemplos de números para experimentar.
- Utilização de `BigInt` para representar resultados inteiros de grande magnitude.

## Tecnologias utilizadas

- **HTML5:** estrutura da aplicação.
- **CSS3:** estilização da interface.
- **JavaScript:** lógica de cálculo e interatividade.
- **Git e GitHub:** versionamento e armazenamento do código.
- **GitHub Pages:** hospedagem da aplicação.

## Como executar localmente

1. Clone o repositório:

   `git clone git@github.com:AntonioBruno/calculadora-fatorial.git`

2. Abra a pasta do projeto no VS Code.
3. Abra o arquivo `index.html` em um navegador.

Projeto desenvolvido como exercício prático de programação front-end, aplicando conceitos de HTML, CSS, JavaScript e controle de versões com Git.
